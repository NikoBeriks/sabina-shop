# 🛍️ Магазин Хавпачевых — Интернет-магазин

Полноценный интернет-магазин на **Next.js 14 + TypeScript + Tailwind CSS + SQLite (Prisma ORM)**.

## Быстрый старт

```bash
# 1. Установите зависимости
npm install

# 2. Создайте базу данных
npm run db:push

# 3. Заполните тестовыми данными
npm run db:seed

# 4. Запустите в режиме разработки
npm run dev
```

Откройте [http://localhost:3000](http://localhost:3000) — магазин.  
Откройте [http://localhost:3000/admin](http://localhost:3000/admin) — админ-панель.

## Настройка WhatsApp

Номер владельца магазина для приёма заказов уже настроен в файле `.env`:
```env
NEXT_PUBLIC_WHATSAPP_NUMBER=79287144816
OWNER_WHATSAPP_NUMBER=79287144816
```
Сразу после оформления заказа покупателю открывается готовое сообщение в WhatsApp с номером заказа, списком продуктов, адресом и суммой, адресованное напрямую на номер `+7 (928) 714-48-16`.

## Структура

| Путь | Описание |
|---|---|
| `/` | Каталог товаров |
| `/checkout` | Оформление заказа |
| `/order/[id]` | Подтверждение заказа + WhatsApp |
| `/chat` | Чат поддержки (клиент) |
| `/admin` | Дашборд |
| `/admin/products` | Управление товарами |
| `/admin/orders` | Управление заказами |
| `/admin/scanner` | Barcode/QR сканер |
| `/admin/chat` | Чат поддержки (админ) |

## Технологии

- **Next.js 14** App Router + TypeScript
- **Tailwind CSS** v4
- **Prisma ORM** + SQLite (локальная БД)
- **Zustand** — состояние корзины (с персистентностью)
- **html5-qrcode** — сканирование через камеру
- **lucide-react** — иконки
